  1. Add the property details and a building image.
  2. Add configurations, full-rupee prices, area basis and a floor-plan image for each.
  3. Select amenities, add connectivity and confirm your contact details.
  4. Click Generate landing page. Review Wide and Mobile previews, then open the full preview to check the final width.
  5. Download the single HTML file. Open it in a browser or upload it to your website.

Making your URL live

The URL name controls the downloaded filename. For yourwebsite.com/your-property-name/, create a folder called your-property-name on your hosting and put the exported file inside it as index.html. Simply generating the file does not publish it.

Saving and reusing listings

Your current draft auto-saves in this browser when IndexedDB is available. Use Save backup for each property before starting another. The JSON backup contains all inputs and images. Import it later to edit and regenerate. Clearing browser data deletes local drafts; keep downloaded backups.

Images, prices and accuracy

Building photos are resized to at most 1,920 pixels and compressed as JPEG. Plans retain a lossless PNG format, resized to at most 2,400 pixels. Prices must be full rupee amounts. The tool does not verify property facts, registration numbers, availability, amenities or travel times. Review your uploaded plan and all details before publishing.

What stays in the file

HTML, CSS, JavaScript and images are embedded in one file. Internet is needed for Google Fonts, WhatsApp and phone actions. The page works offline with a fallback font. There is no backend, lead database, analytics or automatic publishing.
